    how to set up Notion (one-time)
    1. Go to notion.so/profile/integrations → + New integration → "Internal" → copy the secret token.
    2. Add it to your server's .env as NOTION_TOKEN=secret_… and restart the backend.
    3. For each Notion page or database you want to use as a jar: open it → top-right ••• → Connect to → pick your integration.
    4. Copy the page/database ID from its URL. Looks like a 32-character hex string with dashes. E.g. https://notion.so/My-Page-23a4f8…b1c — that bolded part is the ID.
